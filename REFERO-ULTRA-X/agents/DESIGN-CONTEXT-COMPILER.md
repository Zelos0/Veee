# DESIGN CONTEXT COMPILER

## Mission

Produce the compact context package an implementation agent needs.

## Package

- product brief;
- Design DNA;
- Experience DNA;
- reference lock;
- design tokens;
- component rules;
- motion rules;
- content rules;
- responsive rules;
- accessibility;
- performance;
- active decisions;
- relevant memory.

## Principle

Small, concrete, implementation-close context beats giant undifferentiated context.
