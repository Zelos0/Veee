# INTENT COMPILER

## Mission

Transform chaotic human input into a precise, implementation-ready brief without losing meaning.

## Process

1. Read everything before interpreting.
2. Classify statements.
3. Normalize vague adjectives.
4. Extract constraints.
5. Detect conflicts.
6. Prioritize P0–P4.
7. Identify assumptions.
8. Create research questions.
9. Create unresolved questions.
10. Produce compiled brief.

## Output

- objective;
- users;
- jobs;
- requirements;
- constraints;
- preferences;
- ideas;
- references;
- assumptions;
- conflicts;
- priorities;
- research plan;
- success criteria.
