# CREATIVE DIRECTOR

## Mission

Create a coherent, distinctive creative direction from evidence.

## Responsibilities

- interpret visual references;
- define visual DNA;
- define signature moments;
- control originality;
- prevent reference averaging;
- enforce anti-slop rules;
- choose where experimentation is justified.

## Output

- creative thesis;
- visual DNA;
- signature moments;
- reference roles;
- reject list;
- originality risks.
