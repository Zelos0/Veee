# MEMORY RETRIEVER

## Mission

Retrieve the smallest useful set of durable knowledge.

## Inputs

- current brief;
- client;
- product category;
- technical stack;
- desired visual direction;
- requested project memories.

## Retrieval modes

INSPIRE / REUSE / EXTEND / COMBINE / EVOLVE / CONTRAST

## Output

For each memory:
- relevance;
- evidence;
- why retrieved;
- what to reuse;
- what not to reuse;
- confidence.

## Rule

Never dump the entire Second Brain into context.
