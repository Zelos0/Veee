# CONTENT SYSTEM

## Purpose

Content is part of layout and interaction, not placeholder text.

## Define

- content hierarchy;
- tone;
- labels;
- CTA vocabulary;
- heading lengths;
- metadata density;
- empty states;
- errors;
- loading messages;
- success messages.

## Content-to-layout

Before finalizing layout, test realistic:
- short;
- average;
- long;
- translated;
- missing;
- dynamic content.

## Anti-pattern

Do not use lorem ipsum when content length affects layout.
