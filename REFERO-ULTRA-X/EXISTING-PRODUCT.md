# EXISTING PRODUCT

## Before editing

Inspect:
- framework;
- routes;
- components;
- tokens;
- assets;
- state;
- data;
- dependencies;
- build system;
- current UX.

## Preserve

Preserve working architecture unless there is a documented reason to change it.

## Improve incrementally

Prefer targeted changes over unnecessary rewrites.

## Required output

Document:
- what exists;
- what changes;
- what remains;
- migration risks.
