# REFERO ULTRA X — Persistent Design Intelligence OS

## Purpose

REFERO ULTRA X is a modular operating system for AI-assisted product, UX, visual design, frontend implementation, research, quality assurance, and long-term project memory.

The central principle is:

> The chat is not the system of record. The project and Second Brain are.

A user may provide ideas as an unstructured brain dump. The system compiles intent, researches Refero and external inspiration, synthesizes a coherent design direction, locks references, creates a design system, implements the product, renders and audits the result, documents itself, and writes durable knowledge back into memory.

## Core loop

```text
HUMAN INPUT
  ↓
INTENT COMPILER
  ↓
MEMORY RETRIEVAL + NEW RESEARCH
  ↓
REFERENCE SYNTHESIS
  ↓
REFERENCE LOCK
  ↓
DESIGN / MOTION / CONTENT SYSTEM
  ↓
IMPLEMENTATION
  ↓
SELF-DOCUMENTATION
  ↓
RENDER / QA / USER SIMULATION
  ↓
FIX / RE-RENDER
  ↓
POSTMORTEM
  ↓
SECOND BRAIN UPDATE
```

## High-impact visual reconstruction

For ambitious visual work, read `CREATIVE-EXCELLENCE.md`, `REFERENCE-INTELLIGENCE.md`, and `IMAGE-TO-CODE.md`. For motion-heavy work, also use `MOTION-RECONSTRUCTION.md`. Before major implementation, create a screen-specific `VISUAL-SPEC.md` from `VISUAL-SPEC-TEMPLATE.md`. The goal is not to jump directly from a screenshot to code: compile evidence into a specification and motion map, implement, render at matching viewports, compare, and iterate. Use `BENCHMARK-SUITE.md` to test this skill against three distinct experience types.

## Design principles

- Preserve meaningful user information.
- Research before committing to visual direction.
- Never average references into a generic midpoint.
- Treat memory as evidence, not authority.
- Keep source provenance.
- Prefer principles over copying.
- Build systems, not isolated screens.
- Motion communicates hierarchy and interaction; it is a first-class design layer, not decoration.
- Reference findings must distinguish observed evidence, inference, and unknowns.
- Immersive 3D is a specific experience strategy, not a universal upgrade.
- Benchmark with repeatable captures and evidence, not subjective memory alone.
- Mobile is an intentional composition, not a shrunken desktop.
- Accessibility and performance are design constraints.
- QA is part of implementation.
- Documentation is part of implementation.
- Every major decision should be recoverable after chat context is gone.
