# REFERO RESEARCH

## Research objective

Use Refero as structured design evidence, not as a gallery.

## Research layers

### Styles
Use for:
- visual direction;
- typography;
- color;
- composition;
- design-system cues.

### Screens
Use for:
- concrete UI;
- page anatomy;
- component patterns;
- hierarchy.

### Flows
Use for:
- multi-step journeys;
- onboarding;
- checkout;
- account flows;
- complex interactions.

## Research process

1. Start from compiled intent.
2. Search narrowly.
3. Collect candidates.
4. Inspect details.
5. Extract principles.
6. Compare candidates by role.
7. Select references.
8. Record rejected references and why.
9. Create Reference Lock.

## Refero MCP

Use the currently exposed Refero MCP tool names rather than assuming stale names. Common capabilities include style search/detail, screen search/detail/similarity/image, and flow search/detail.

## Research record

For each useful source:
- source ID / URL;
- type;
- query;
- role;
- useful traits;
- rejected traits;
- confidence;
- project usage.

## Rule

Never say "this looks good" without identifying what specifically is being learned.

## Mandatory execution contract (v2.3)

This document is an execution protocol, not a reminder to perhaps research later. For high-impact UI work:
1. Inspect the live MCP tool registry and schemas in the current agent environment.
2. Call the available Refero search tools with 4–8 task-specific queries.
3. Use available detail/similarity/image/flow tools to inspect candidates beyond titles.
4. Evaluate multiple candidates and create a project-local `REFERENCE-RESEARCH.md`.
5. Include the actual tools called and evidence returned.
6. Do not default to examples or benchmark fixtures. Exat, Lando Norris, and Messenger are useful benchmark cases only, unless current research shows they fit the project.

Read and follow `MCP-RESEARCH-PROTOCOL.md`. If no tools are callable, document the exact limitation and label the MCP portion incomplete. A server name in settings or a mention in a plan does not count as usage.
