# RESPONSIVE ART DIRECTION

## Principle

Mobile is not a smaller desktop.

## Define separately

### Desktop
- composition;
- navigation;
- motion;
- density.

### Tablet
- reflow;
- interaction adaptation;
- content priority.

### Mobile
- hierarchy;
- stacking;
- navigation;
- touch targets;
- motion reduction;
- content prioritization.

## Art direction

Elements may:
- move;
- disappear;
- transform;
- change interaction;
- change crop;
- change order.

## Device profiles

Consider:
- high-performance desktop;
- standard laptop;
- tablet;
- mobile;
- reduced-motion;
- low-bandwidth;
- touch-only.
