# PERFORMANCE

## Principle

Premium means responsive.

## Audit

- image size;
- formats;
- responsive images;
- fonts;
- JS;
- bundle size;
- hydration;
- layout stability;
- WebGL;
- animation;
- third-party scripts.

## Adaptation

Heavy experiences should have capability-aware fallbacks.

Examples:
- reduced WebGL resolution;
- simplified effects;
- reduced motion;
- static media fallback;
- deferred non-critical effects.

## Rule

Never sacrifice core usability for spectacle.
