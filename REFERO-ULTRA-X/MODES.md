# MODES

## STANDARD

Reliable product work with minimal creative risk.

## PREMIUM

Higher visual craft, stronger typography, composition, motion, and polish.

## CREATIVE

More experimentation and distinctive interaction.

## ULTRA

Full system:
- memory;
- research;
- multi-agent synthesis;
- advanced interaction;
- self-documentation;
- visual QA;
- originality review;
- postmortem.

## User control

The user can explicitly request:
- inspiration only;
- reuse a project;
- contrast against a project;
- full new research;
- conservative mode;
- experimental mode.
