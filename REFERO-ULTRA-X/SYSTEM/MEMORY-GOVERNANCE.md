# MEMORY GOVERNANCE

## Principles

- user-owned;
- model-neutral;
- provenance-preserving;
- evidence-aware;
- conflict-aware;
- compact;
- reversible.

## Never store

- irrelevant chat noise;
- secrets;
- credentials;
- unnecessary personal data;
- unsupported assumptions as facts.

## Retention

Keep durable knowledge that can improve future work.
Archive knowledge that is obsolete but historically useful.
