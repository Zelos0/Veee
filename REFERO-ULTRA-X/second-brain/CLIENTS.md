# CLIENT MEMORY

Store only durable, relevant project knowledge.

## Client DNA

- brand preferences;
- typography preferences;
- color preferences;
- density;
- motion tolerance;
- interaction tolerance;
- approved references;
- rejected references;
- accessibility requirements;
- technical constraints;
- business priorities;
- communication preferences relevant to execution.

## Rule

Client memory is context, not authority. Current explicit instructions override it.
