# SECOND BRAIN SYSTEM

## Retrieval modes

### INSPIRE
Extract principles from prior work.

### REUSE
Reuse a validated design/system pattern.

### EXTEND
Start from an existing project and evolve it.

### COMBINE
Combine selected prior projects with new research.

### EVOLVE
Analyze what worked and failed, then improve it.

### CONTRAST
Intentionally differentiate from an existing project.

## Borrowing budget

Assign different principles to different sources to avoid cloning.

## Serendipity

Optionally retrieve relevant but unexpected references outside the current design bubble.

## Memory firewall

Never let memory silently override current user requirements.
