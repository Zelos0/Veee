# DESIGN INTELLIGENCE GRAPH

## Purpose

Represent relationships between knowledge rather than storing isolated notes.

## Nodes

- project
- client
- reference
- principle
- pattern
- decision
- implementation
- outcome
- lesson
- failure
- research source

## Edges

- inspired_by
- used_in
- rejected_in
- evolved_from
- contradicted_by
- validated_by
- failed_in
- implemented_as
- resulted_in
- related_to

## Canonical chain

Reference → Principle → Decision → Implementation → Outcome

This allows decision archaeology and evidence-based retrieval.
