# REFERENCE RATING

## Purpose

Evaluate references after actual use.

## Dimensions

Use descriptive evidence, not arbitrary aesthetic scores.

- relevance;
- visual usefulness;
- UX usefulness;
- implementation complexity;
- performance risk;
- originality risk;
- client fit;
- outcome;
- confidence.

## Lifecycle

1. Candidate
2. Used
3. Evaluated
4. Validated / Mixed / Misleading
5. Reusable / Context-specific / Avoid
