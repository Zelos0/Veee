# KI-IT-Mentor + REFERO ULTRA X — integriertes Starterpaket

**Startpunkt:** `START.md`

## Verwendung
1. Öffne diesen Ordner bzw. kopiere ihn in das Ziel-Repository.
2. Starte Claude Code im Zielprojekt.
3. Lass Claude `START.md` vollständig lesen und ausführen.
4. `START.md` verlangt ausdrücklich, `REFERO-ULTRA-X/START-HERE.md` zu lesen und den dort beschriebenen Bootstrap/Workflow auszuführen.
5. Siehe `CLAUDE_ACCESS_SETUP.md` für Zugriffs- und Integrationshinweise.

## Inhalt
- `START.md`: vollständiger Arbeitsauftrag
- `CLAUDE_IMPLEMENTATION_GUIDE.md`: detaillierte Produktspezifikation
- `CLAUDE_ACCESS_SETUP.md`: Zugang und Freigaben
- `REFERO-ULTRA-X/`: extrahierter Refero Ultra X 2.3 Skill
- `inputs/REFERO-ULTRA-X-v2.3-original.zip`: Originalarchiv als Referenz

Das Paket enthält Anweisungen und Referenzdateien, aber nicht die implementierte Anwendung oder Zugangsdaten. Claude Code muss die Integration im Ziel-Repository durchführen.
